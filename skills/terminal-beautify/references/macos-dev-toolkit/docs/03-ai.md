## OpenCode

> [OpenCode](https://opencode.ai) 开源的 AI 编程助手，支持 TUI、桌面应用和 IDE 扩展。

### 安装
```bash
npm install -g opencode-ai
# 或 curl -fsSL https://opencode.ai/install | bash
# 或 brew install anomalyco/tap/opencode
```

### 初始化
```bash
cd /path/to/project
opencode      # 运行 /init 创建 AGENTS.md
```

### 配置自定义 Provider

`opencode.json`（项目根目录）：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "anthropic/claude-sonnet-4-5",
  "provider": {
    "my-custom-provider": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "My Custom LLM",
      "options": {
        "baseURL": "https://api.my-provider.com/v1",
        "apiKey": "{env:MY_API_KEY}"
      },
      "models": {
        "my-model": {
          "name": "My Model",
          "limit": { "context": 200000, "output": 65536 }
        }
      }
    }
  }
}
```

**环境变量**：
```bash
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENCODE_MODEL="anthropic/claude-sonnet-4-5"
```

**DeepSeek 示例**：
```json
{
  "provider": {
    "deepseek": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "DeepSeek",
      "options": {
        "baseURL": "https://api.deepseek.com/v1",
        "apiKey": "{env:DEEPSEEK_API_KEY}"
      },
      "models": {
        "deepseek-chat": { "name": "DeepSeek V3" },
        "deepseek-reasoner": { "name": "DeepSeek R1" }
      }
    }
  }
}
```

### Skills（角色技能）

### 🎯 统一技能安装（npx skills add）

所有 Agent Skills 生态的技能均可通过统一的 `npx skills add` 命令安装，它会自动检测当前使用的 AI 编程代理并安装到正确位置。

```bash
# 先安装 npx 技能管理器（如未安装会自动处理）
# 然后使用以下命令安装所需技能

# 安装全部技能
npx skills add mattpocock/skills           # 工程技能（grill-with-docs, tdd 等）
npx skills add obra/superpowers            # 完整开发方法论（brainstorming, sdd 等）

# 安装单个技能
npx skills add mattpocock/skills --skill grill-with-docs
npx skills add mattpocock/skills --skill tdd
npx skills add mattpocock/skills --skill code-review
npx skills add mattpocock/skills --skill diagnosing-bugs
npx skills add mattpocock/skills --skill improve-codebase-architecture
npx skills add mattpocock/skills --skill to-prd
npx skills add mattpocock/skills --skill research
npx skills add mattpocock/skills --skill prototype
npx skills add mattpocock/skills --skill triage
npx skills add mattpocock/skills --skill to-issues

# 安装指定仓库中的特定技能
npx skills add anthropics/skills --skill skill-creator    # 🛠️ 技能创建器：自定义专属技能
npx skills add anthropics/skills --skill frontend-design  # 前端设计技能
npx skills add obra/superpowers --skill writing-skills    # 学习如何编写高质量技能

# 安装后运行初始化（只对带 setup 的技能需要）
# /setup-matt-pocock-skills
```

### 🛠️ 自定义技能：skill-creator

> [skill-creator](https://skills.sh/anthropics/skills/skill-creator) (301k 安装量) 是 Anthropic 官方提供的技能创建工具，
> 让你通过对话引导的方式创建属于自己的 Agent Skills，无需手动编写 SKILL.md。

```bash
# 安装 skill-creator
npx skills add anthropics/skills --skill skill-creator

# 安装完成后，在 agent 中使用以下指令启动创建向导：
# /create-skill
```

**skill-creator 可以创建的优势：**
- 团队代码规范：自定义项目的编码规范、命名约定、架构决策记录
- 项目特定流程：CI/CD 流程、部署检查清单、代码审查标准
- 领域专业知识：特定框架/库的最佳实践、内部工具使用指南
- 跨角色协作：设计师→开发的交接规范、测试用例编写标准

**手写 SKILL.md 模板：**
```markdown
---
name: my-custom-skill
description: A clear description of what this skill does and when to use it
---
# My Custom Skill
Detailed instructions that the agent will follow when this skill is active.
```

## Oh My Pi (Pi Agent)

> [omp](https://omp.sh) 高性能终端 AI 编程代理，Rust 核心，40+ Provider、LSP/DAP、子代理。

### 安装
```bash
curl -fsSL https://omp.sh/install | sh
# 或 brew install can1357/tap/omp
# 或 bun install -g @oh-my-pi/pi-coding-agent
eval "$(omp completions zsh)"  # Shell 补全
```

### 初始化
```bash
cd /path/to/project
omp
```

### 配置自定义 Provider

`.omp/config.json`：
```json
{
  "provider": {
    "openai": { "apiKey": "{env:OPENAI_API_KEY}", "baseURL": "https://api.openai.com/v1" },
    "anthropic": { "apiKey": "{env:ANTHROPIC_API_KEY}", "baseURL": "https://api.anthropic.com/v1" },
    "custom": {
      "type": "openai-compatible",
      "name": "My Provider",
      "apiKey": "{env:MY_API_KEY}",
      "baseURL": "https://api.my-provider.com/v1",
      "models": ["my-model-1"]
    }
  },
  "model": "anthropic/claude-sonnet-4-5",
  "small_model": "anthropic/claude-haiku-4-5"
}
```

### 多 Key 轮询
```json
{
  "provider": {
    "openai": {
      "apiKey": ["{env:OPENAI_API_KEY_1}", "{env:OPENAI_API_KEY_2}"],
      "retry": { "fallbackChains": { "primary": ["openai", "anthropic"], "cheap": ["groq", "deepseek"] } }
    }
  }
}
```
