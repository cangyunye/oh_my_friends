# oh_my_friends 🛠️

Personal skill & toolkit notebook. OpenCode skills, productivity tools, dev environment setups, and software installation guides — everything I want to keep and reuse.

## contents

| directory | what |
|-----------|------|
| `skills/` | OpenCode skills (for AI-assisted workflows) |
| — `terminal-beautify/` | 跨平台终端美化方案 (Windows/Linux/macOS) |

## what goes here

- **OpenCode skills** — reusable instructions for AI-assisted tasks
- **Dev toolkit configs** — terminal beautification, editor setup, shell config
- **Software installation plans** — office tools, dev tools, cross-platform
- **Productivity recipes** — anything worth automating or documenting

## structure

Each skill lives in `skills/<name>/` with a `SKILL.md` (frontmatter + markdown). Supporting docs go in `references/`, evaluation scenarios in `evals/`.
